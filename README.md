# Мелони и Лисси — Fabric 1.21.1 (порт MeloniLissiAddon v1.2.0)

Требования: JDK 21, Minecraft 1.21.1, Fabric Loader ≥ 0.16, Fabric API, **GeckoLib ≥ 4.7** (для 1.21.1).

## Сборка
    gradle wrapper --gradle-version 8.10   # один раз, если нет gradlew
    ./gradlew build                        # jar: build/libs/nyasha-companions-1.2.0.jar
    ./gradlew runClient                    # тест в песочнице

## Игра
- **Сердце Мелони / Сердце Лисси** (вкладка «Ингредиенты») — ПКМ: создать спутницу (выбор характера кликом в чате), позвать, если далеко.
- ПКМ по ней: меню действий в чате (кликабельные кнопки). ПКМ с предметом в руке — подарок. Shift+ПКМ — идти за тобой / стоять.
- Свободный чат: пиши «Лисси, привет», «Мелони, как дела?» в чат. Или `/nyasha say <текст>`.
- Команды: `/nyasha act|reply|create|say|info`.
- Id сохранены: `nyasha:creeper`, `nyasha:lissi`, `nyasha:heart`, `nyasha:lissi_heart`.

## LLM (необязательно)
`config/nyasha.json` → `llm.enabled=true`, endpoint (OpenAI-совместимый), model, apiKey.
Отдельный пак `Nyasha_LLM_BP` не нужен: в Java HTTP работает напрямую.

## Что перенесено
Модели/текстуры/анимации (GeckoLib), характеры (cute/tsundere/meek/sly), 4 параметра отношений, этапы дружбы/любви,
защита от накрутки, ссоры/примирения, подарки, ~600 диалогов из JSON (data/nyasha/dialogues), реакции на ответы,
эмоции/действия → анимации, ИИ (следование, защита хозяина, бегство при низком HP), забота (регенерация),
пощёчина у «стервы», обращение по имени/взгляду, сохранение профилей в мире.

## Что ещё НЕ перенесено (из исходных скриптов)
mind.js / lissi_mind.js (генеративный локальный движок фраз), phrasebook, persona_data, understand.js, lessons.js,
worldctx.js (подробное описание мира), события event_manager (ревность, стройка, костёр, взрывы, смерть игрока и т.д.),
кино-камера поцелуя, красный оверлей при поцелуе, обещания. Сейчас свободный чат — простой локальный классификатор + LLM.
